## 업무 흐름에 걸린 화면 상태

[SWING 운영 Admin](/#archive-swing-admin)은 운영자가 여러 메뉴를 오가며 쓰는 도구예요. 로그인 직후 사용자 정보와 메뉴가 갱신되는 순서, 세션 만료, 이전 화면으로 돌아올 때의 상태가 화면에 영향을 줬습니다. 저는 이 과정에서 생기는 UI 문제를 수정하고, 파트너 정산 요약과 정산서별 운행 내역을 찾고 조회하는 화면을 구현했어요. 정산 화면을 만들었다는 기록은 정산 계산 자체를 설계하거나 검증했다는 주장과는 구분합니다.

기존 JavaScript·MUI 기능을 TypeScript·Ant Design 기반으로 옮기는 작업에도 참여했어요. 도메인별 Admin 분리와 모노레포 통합 과정에서 한 화면의 변경이 다른 운영 작업에 어떤 영향을 주는지 살피는 일이 중요했습니다. 공개 기록에는 개인정보 마스킹·포맷팅 모듈을 Vitest로 검증하고 npm 패키지로 배포한 기여도 남아 있어요. 이는 공통 표현 로직을 재사용한 작업이며, 데이터 접근 권한이나 보안 체계 전체에 대한 증명은 아닙니다.

공개 아카이브는 작업 항목을 보여 주지만 운영 시간 절감이나 오류율 변화 같은 결과 수치는 담고 있지 않아요. 그래서 이 기록은 제가 맡은 화면과 공통 모듈의 범위, 그리고 확인한 기술 경계에 집중합니다.
