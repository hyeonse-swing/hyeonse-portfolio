## 메뉴를 오간 뒤에도 맞아야 하는 상태

[SWING 운영 Admin](/#archive-swing-admin)에서는 운영자가 여러 메뉴를 오가며 일해요. 로그인 직후 사용자 정보와 메뉴가 갱신되는 순서가 어긋나거나, 세션이 만료되거나, 이전 화면으로 돌아오면 UI 상태가 달라질 수 있었습니다. 저는 이런 문제를 수정하면서 파트너 정산 요약과 정산서별 운행 내역을 찾고 조회하는 화면도 만들었어요. 정산액을 계산하는 로직의 설계·검증은 이 화면 작업의 범위에 포함되지 않았습니다.

기존 JavaScript·MUI 기능을 TypeScript·Ant Design 기반으로 옮기는 작업에도 참여했어요. 도메인별 Admin 분리와 모노레포 통합이 진행돼 한 화면의 변경이 다른 운영 작업에 닿는 부분을 살펴야 했습니다. 개인정보 마스킹·포맷팅 모듈은 Vitest로 검증하고 npm 패키지로 배포한 기여가 공개 기록에 남아 있어요. 공통 표현 로직을 재사용할 수 있게 한 작업이며, 데이터 접근 권한이나 보안 체계 전체를 검증한 것은 아닙니다.

공개 아카이브에는 작업 항목이 남아 있지만 운영 시간이나 오류율이 얼마나 바뀌었는지는 측정된 수치가 없어요.
